# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、色线统计、撤销重做、本地保存和导出JSON。

## 上机织造卡

- 点「生成织造卡」从当前网格生成草稿卡：按横行给出提综队列，每格对应一个经线通道，连续同色投梭合成一段并标注次数与通道范围，卡上同时汇总每色投梭总次数。
- 以下情况只留草稿、不能确认：色线未处理（仍有底色格）、行列与卡片不符（画布改过）、单通道连续提综超过四行（卡上标红，调好重新生成再确认）。
- 卡片确认后画布再变，旧卡自动作废并留档，可在「作废留档」中追溯。

## 文件结构

- `js/weave-card.js`：卡片计算——提综队列生成、同色并段、连续提综检测、确认条件判定
- `js/card-archive.js`：历史存放——当前卡与作废留档的本地持久化
- `js/main.js`：页面操作——画布与卡片面板的渲染和交互
